# PowerOn publisher website

Static site for GitHub Pages. Publish the `web` directory from the repository settings or copy its contents to the Pages branch root.

- `index.html`: publisher landing page and asset catalog
- `voxels-at-work/index.html`: Voxels At Work product page
- `voxels-at-work/docs/index.html`: full product documentation

The site has no build step or external dependencies.
